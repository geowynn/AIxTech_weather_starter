# Deletion Review

## Redundant

- Repeating that the app is TypeScript in multiple places.
- Repeating the workspace split in both the root file and detailed docs.
- Listing every file path in more than one place.
- Restating that `frontend/src/state/store.tsx` is the main client state container in multiple docs.

## Too Vague

- "Prefer TypeScript-aware changes."
- "Keep backend and frontend types aligned."
- "Keep changes scoped to the current task."

These are directionally useful, but they are too broad to act on without more context.

## Overly Obvious

- "Write clean code."
- "Use small changes."
- "Add tests."
- "Prefer explicit types."

## Keep

- The API endpoint list.
- The database path and migration path.
- The environment variable list.
- The development and test commands.
- The backend/frontend architecture summary.
